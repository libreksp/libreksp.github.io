## The Klondike License Family:

### [Klondike Commons License (KCL)](/licenses/kcl.md)

A public domain dedication. Use, modify, distribute, or sell this software however you want with no restrictions.

### Pico-KPL (Pico Klondike Public License) - **PLANNED**

Permissive open source license. Free to use in any project, including proprietary software, with attribution required.

### Micro-KPL (Micro Klondike Public License) - **PLANNED**

Weak copyleft for libraries. Can be used in proprietary software, but modifications to the library itself must remain open source.

### KPL (Klondike Public License) - **PLANNED**

Strong copyleft license. Derivative works must be released under the same license, ensuring software freedom is preserved.

### Macro-KPL (Macro Klondike Public License) - **PLANNED**

Network copyleft license. Like KPL, but also requires source code disclosure for software accessed over a network (SaaS/cloud).

### Librebook License - **PLANNED**

Copyleft license for documentation and written works. Derivatives must preserve freedom, ensuring knowledge remains open.

### Micro Librebook License - **PLANNED**

Permissive license for documentation and books. Free to use and modify with attribution, no copyleft requirement.

### MediaLibre License - **PLANNED**

Copyleft license for visual and audio media. Ensures creative works and derivatives remain freely available.

### Micro MediaLibre License - **PLANNED**

Permissive license for images, video, and audio. Free to use and remix with attribution, no copyleft requirement.
